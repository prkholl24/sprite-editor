<h1>Sprite Editor</h1>
<h2>Summary</h2>
<p>
  This program was designed in Qt Creator and allows users to create and animate pixel art. 
</p>
<h2>Features</h2>
<p>
  Sprite Editor allows users to create their own pixel art on a custom size pixel grid, as well as add frames to make animated sprites. 
  Sprite Editor features a variety of tools to assist in your <i><b>spritefull</b></i> creations. 
  To save your memories made in Sprite Editor, projects can be saved and loaded as a json. 
</p>
<h2>How to Run</h2>
<p>
  To run Sprite Editor, go to the release page of the git hub repository and download "Sprite_Editor_Release.zip".
  Unzip it, open the unzipped folder and run "SpriteEditor.exe"
</p>
<p>
  Additionally, you can clone this project into Qt Create and run the program there. 
</p>
